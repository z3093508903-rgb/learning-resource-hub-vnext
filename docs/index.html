Features

一个学习闭环，不是一堆按钮。

项目式资源中心

本地视频、OpenList、Bilibili、Vault、网页、PDF 放进同一个学习目标里。从“今天学什么”直接进入资源。

Companion 笔记小窗

真实 Obsidian Markdown，可拖入、置顶、独立使用，也可以锁定成 Study Mode 的 Capture 目标。

Alt + S HUD

时间戳、笔记、评论、截图类动作不再反复切窗口。

轻量 Timeline

多视频来源分组，看结构、回正文，不和播放器职责打架。

可恢复的数据安全

自动快照、命名长期备份、任意历史备份选择恢复。

Bilibili

网页里看，也能直接记。

不用为了 B站先折腾 PotPlayer

安装可选的 Go Study Bilibili Bridge 后，Go Study 可以读取当前活动 B站视频的播放时间，直接通过 HUD 写入 Companion 或 Markdown。


Bilibili video.currentTime → 127.0.0.1 → Go Study → Alt + S → [01:09](https://www.bilibili.com/video/BV...?t=69.4)

进阶用户仍然有 PotPlayer

本地课程、OpenList、截图、播放器控制继续交给 PotPlayer。网页轻量路线和进阶路线并存。

为什么首发先做 Bilibili

0.3.0 优先围绕已经实际验证的中国用户视频学习工作流开发。Bilibili Web Bridge 是首发专门适配的平台能力。

YouTube 后续再做

YouTube 目前没有专门的时间戳 / HUD Bridge。未来如果有真实海外用户需求，会按实际学习习惯设计 Adapter，而不是为了首发平台数量仓促加入。

Local first

你的笔记，不需要经过另一个云。

无遥测

不为了统计使用习惯把你的工作流上传出去。

Bridge 只走本机

B站桥接只与 127.0.0.1 上的 Go Study 通讯。

恢复是第一等功能

不仅会备份，也能明确选择哪一份恢复。
