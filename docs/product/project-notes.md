# 产品说明：Project Notes

## 目标

给 Project 一个轻量笔记上下文，而不是建立复杂永久关系数据库。

## Notes Box

Project 可设置 Vault Folder。

配置 Folder ≠ 自动导入。

## Recent Note

记录 Project 最近实际使用的 Markdown。

## Study Pair

某次学习：

```text
Resource + Note
```

这是临时上下文，不是永久绑定。

## Create Note

需要支持：

- Project 默认 Folder；
- 单次 override；
- Deep browse；
- Search；
- Breadcrumb。

## Continue Learning

优先做到：

- 打开正确 Note；
- 可选 focus last line。

先不要自动上 Heading Anchor。
