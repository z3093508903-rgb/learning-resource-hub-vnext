# 产品说明：Interaction Principles

## 1. 低摩擦优先

少而强的入口优于功能堆叠。

## 2. Continue Learning 优先于 Manage Learning

Persistent UI 优先显示：

- Resume；
- Recent Context；
- Launch。

## 3. 高频行为键盘化

尤其 Capture。

## 4. 避免 Shortcut Explosion

新组合优先变成 Preset / Template。

## 5. 新用户可发现，高级用户可直达

HUD 给新用户看。

熟练用户走：

`Alt+S → Direction`

## 6. Optional Integration 必须 Graceful Fail

PotPlayer / OpenList / Bilibili 出问题：

不能拖垮普通 Workbench。

## 7. Identity 不明确时 Fail Closed

不要猜当前媒体属于哪个 Resource。

## 8. 错误使用产品语言

优先：

> “Go Study 无法安全确认当前视频属于哪个已管理资源。”

而不是：

> “resolver guard mismatch”。
