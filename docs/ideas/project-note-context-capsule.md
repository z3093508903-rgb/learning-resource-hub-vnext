# Project Note Context Capsule（项目笔记上下文胶囊）

> Status: Future idea / not part of Project Note Box v1
>
> Recorded: 2026-08-26

## 灵感

当用户正在 Obsidian 中阅读一篇已经关联到 Go Study 项目的 Markdown 笔记时，不要求用户回到 Go Study 工作台，也不要求同时打开很多标签页。

在笔记阅读 / 编辑界面提供一个**非常轻量、可关闭的悬浮胶囊**。

默认状态只占很小空间，不干扰正文阅读；点击后扩展为一个小型上下文面板。

## 核心体验

```text
正在阅读某篇项目笔记
        ↓
右侧 / 角落出现轻量胶囊
        ↓
点击胶囊
        ↓
展开项目上下文面板
        ├─ 这篇笔记关联在哪个项目
        ├─ 同项目的其他关联笔记
        ├─ 同项目的学习资料 / Resource
        ├─ 最近学习资源 / Resume
        └─ 继续学习
        ↓
直接切换笔记或启动资料
        ↓
无需预先打开很多 Obsidian 页面
```

## 胶囊状态

### 收起

只展示最少信息，例如：

```text
[ Go Study · 高等数学 ]
```

或更小：

```text
[ GS · 高数 ]
```

原则：
- 不遮挡正文
- 不制造新的常驻大侧栏
- 不要求用户维护额外布局
- 可以拖动 / 记住位置（后续再决定）

### 展开

点击后变成一个小方块 / Popover，而不是完整页面：

```text
┌────────────────────────────┐
│ 高等数学                   │
│                            │
│ 继续学习                   │
│ 极限的定义 · 18:42         │
│                            │
│ 相关笔记                   │
│ • 高数课堂笔记             │
│ • 极限整理                 │
│ • 错题记录                 │
│                            │
│ 相关资料                   │
│ • 第 01 讲 极限            │
│ • 第 02 讲 连续            │
└────────────────────────────┘
```

用户可以直接在这个面板里：
- 切换到同项目的其他笔记
- 打开 / 继续学习项目资源
- 查看当前笔记属于哪个项目

## 产品意义

这不是一个新的“项目管理页面”，而是把 Go Study 的项目上下文带到**学习真正发生的笔记页面**。

它解决的问题是：

> 我已经在读笔记了，如何在不离开当前阅读上下文、不预先打开很多标签页的情况下，快速访问这个项目相关的笔记和资料？

因此它可以成为未来“继续学习”的另一种入口：

```text
工作台里的「继续学习」
        和
笔记里的「项目上下文胶囊」
```

本质上消费同一套数据：
- project
- project note references
- recent study
- resource
- resume position

## 设置

设置中提供明确开关，例如：

```text
笔记项目胶囊
[✓] 在已关联项目的笔记中显示
```

默认行为后续再通过 Preview 决定，但必须允许完全关闭。

未来可继续细分：
- 仅编辑模式显示
- 阅读模式也显示
- 胶囊位置
- 是否显示最近学习资源

这些都不是第一版必做项。

## 与未来 Project Workspace / 多窗口的关系

胶囊不等于 Project Workspace。

它是更轻的一层：

```text
现在：笔记上下文胶囊
未来：项目工作区 / 项目独立窗口
```

即使未来出现：

```text
Project A → Window A
Project B → Window B
```

胶囊仍然可以作为“当前笔记 → 项目工作区”的轻量入口。

## 设计边界

1. **不创建永久 Resource → Note 绑定。**
   当前笔记只需要属于项目；最近学习组合仍记录用户实际使用的资源和笔记。

2. **不取代 Obsidian 标签页。**
   胶囊只是快速导航 / 上下文入口。

3. **不变成第二个侧栏。**
   收起时必须足够轻；展开也应是临时 Popover。

4. **不影响普通阅读。**
   设置可关闭；没有项目关联的笔记完全不出现。

5. **复用 Project Note Box v1 的数据。**
   不另造一套“胶囊专用笔记关系”。

## 可能的演进路径

```text
Project Note Box v1
↓
笔记可以知道自己属于哪些 Go Study 项目
↓
Context Capsule v0
↓
项目内快速切换笔记 / 资料
↓
继续学习入口融合
↓
未来可选 Project Workspace / 独立窗口
```

## 一句话定义

> **在笔记旁边放一个几乎不打扰阅读的项目上下文入口：需要时展开整个项目，不需要时只是一颗小胶囊。**
