## beta.16 Freeform jv 修复候选

重新审查 beta.15 Freeform 回链后确认根因：

```text
obsidian://go-study?mode=freeform&path=...
```

其中 `path` 与 Obsidian 自身 Vault 路由参数冲突，插件 protocol handler 可能尚未接管就先出现 `Vault not found`。

同时核对旧 `markdown2potplayer` 实现，确认原协议为：

```text
jv://open?path=<media>&time=<HH:MM:SS>
```

而 Go Study 自身 `toPotPlayerUri()` 也已经使用同一 `jv://` 语义。

因此建立隔离修复分支：

`fix/freeform-jv-reopen-v1`

策略：

- Managed：保持 `obsidian://go-study?resource=...` + Resource ID + Resolver；
- New Freeform：直接输出 `jv://open?path=...&time=...`；
- Old beta.15 Freeform：在 Obsidian 文档点击层尝试抢先拦截并交给现有 `openFreeformReference()`；
- 不恢复 Companion polling，不把 AHK/Companion 变成整个产品的必须依赖。
